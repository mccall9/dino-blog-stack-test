# Redesign home — referência biip × marclou × revenue

## Referência (screenshot)

`docs/ref-biip-home.png` — biip.club: headline centrada, busca, chips, **card de comunidade**.

## O que NÃO copiar (produto dino)

- Marketplace / “descubra comunidades” / grid de vários clubes  
- dino = **um** clube (Clube dos Curiosos), não diretório  

## marclou-review (aplicado)

| Princípio | Move |
|-----------|------|
| One thing | Só o Clube dos Curiosos |
| Hero alone sells | Headline + sub + 1 CTA + card do produto |
| One CTA | Primário: Entrar para participar |
| Numbers > adjectives | membros / conversas no card |
| CTA says what happens | “Entrar para participar” |
| Fifth-grader | Linguagem simples pt-BR |
| Show product | Card grande com capa + descrição (como biip card, mas único) |
| 3 colors | paper / ink / green |

## revenue-centric (aplicado)

| Princípio | Move |
|-----------|------|
| 5-second test | Problema/desejo no H1, não “plataforma de…” |
| Specificity | “pensar em voz alta” + clube concreto |
| CTA microcopy | o que acontece ao clicar (entrar / participar) |
| Proof before ask | números no card + “conversas reais” |
| Neutrality is omission | CTA preto/verde forte, caminho único |
| Value first | card mostra o clube antes de pedir dados (Fase 2 auth) |

## ui-skills (intent)

CLI `npx ui-skills` instável no ambiente; princípios usados de craft/layout vendorizados:

- hierarchy clara (H1 → lede → CTA → produto)  
- whitespace generoso (referência biip)  
- um accent  
- alvos ≥ 44px, focus-visible  

## Headline escolhida

- **H1:** Pense em voz alta. Ache quem responde.  
- **Sub:** O Clube dos Curiosos — conversas reais, sem marketplace de comunidades.  
- **CTA:** Entrar para participar
